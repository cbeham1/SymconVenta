# Venta Automation

Season automation for Venta Humidifier instances: runs them only in the heating season (heating in winter mode,
24 h mean outdoor temperature below the start value, ventilation running), automatic mode by day and sleep mode by night,
off when nobody is at home or the room is too humid. The instance is a tile with the main switch.
