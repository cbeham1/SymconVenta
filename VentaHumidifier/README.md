# Venta Humidifier

One Venta humidifier/airwasher on the local network (protocol v0 TCP 48000 or v2 HTTP). Variables for humidity,
temperature, water, fan, mode, target humidity, LED, maintenance (hygiene disc, cleaning) and the instance as tile.

Setup: enter the IP address, protocol *automatic*. v0 devices (LPH60 …) must be authorized once on the device.
See the [main README](../README.md) for details, functions and the notification script.
